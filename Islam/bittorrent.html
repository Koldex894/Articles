Downloading the Complete Content of Answering Islam

For some years, we have made the content of the Answering Islam website available also as CD-ROM, and we regularly offered incremental online updates for it.

The current DVD version of Answering Islam is now available via BitTorrent.

BitTorrent is a peer-to-peer network which allows you to download a file from whoever else has it and shares it via BitTorrent. To download the Answering Islam DVD via BitTorrent, just download one of the torrent files below and import this torrent file into your BitTorrent client. The file that you download is the same on all torrents but the different torrent files use different trackers and the availability might differ from tracker to tracker.

You can download a ZIP (547MB) or RAR (541MB) archive of the site which you can extract to your hard drive. Or alternatively you can download the ISO image (811MB) which you can directly burn to a DVD.
